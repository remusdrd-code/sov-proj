# 06: Automation and Persistent Overrides

**What to build:** Independent automation switches for every major system, a global switch, idle unassigned work when automation is off, and manual orders that persist until revoked.

**Blocked by:** 03: Project Lifecycle and Construction Gating; 05: Resource Flows and Fractional Operation

**Status:** ready-for-agent

- [ ] Industry, building, transport, logistics, imports, staffing, maintenance, and project sequencing each have an independent automation switch.
- [ ] A global switch can enable or disable automation across all supported systems.
- [ ] Automation-off systems leave unassigned work idle and expose it through an action queue.
- [ ] Manual overrides take precedence over automation and remain active until revoked.
